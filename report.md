## 2. Що тестуємо та очікувана поведінка

| Компонент | Як має працювати |
| :--- | :--- |
| Кошик `CartService` | Додає товари з ціною та кількістю. Сума кошика = сума (ціна × кількість). Метод `getFinalTotal(знижка)` рахує суму і застосовує до неї `calculateDiscount()` |
| Знижка `calculateDiscount()` | `100, 10% -> 90`; `100, 0% -> 100`; `100, 100% -> 0`. Якщо знижка поза межами 0-100, виникає помилка `Discount must be between 0 and 100` |
| Шлюз `ExternalEchoGateway` | Надсилає номер замовлення та суму на зовнішній сервіс Postman Echo. Сервіс повертає назад ті самі параметри у полі `args` |

Додав два нові файли:

- [`src/cart-service.js`](src/cart-service.js) - кошик, який використовує функцію знижки;
- [`src/external-echo.gateway.js`](src/external-echo.gateway.js) - шлюз, який робить HTTP-запит до Postman Echo.

## 3. Тест взаємодії компонентів

Перевіряється зв'язка двох наших компонентів: **кошик + функція знижки**.

### Сценарій 1 - Знижка на кошик

```javascript
// Підготовка: кошик з двома товарами
const cart = new CartService();
cart.addItem(100);
cart.addItem(200);

// Дія: отримуємо суму зі знижкою 10%
const result = cart.getFinalTotal(10);

// Перевірка
expect(result).toBe(270);
```

Очікуваний результат: `100 + 200 = 300`, знижка 10% -> `270`.

| Вхідні дані | Очікувано | Отримано | Результат |
| :--- | :--- | :--- | :--- |
| товари 100 і 200, знижка 10% | `270` | `270` | Пройдено |

### Сценарій 2 - Неправильна знижка (негативний тест)

Перевіряємо, що помилка з функції знижки передається через кошик до того, хто викликав метод.

```javascript
const cart = new CartService();
cart.addItem(100);

expect(() => cart.getFinalTotal(110)).toThrow(
    'Discount must be between 0 and 100'
);
```

| Вхідні дані | Очікувано | Отримано | Результат |
| :--- | :--- | :--- | :--- |
| товар 100, знижка 110% | помилка `Discount must be between 0 and 100` | ця сама помилка | Пройдено |

## 4. Тест взаємодії із зовнішньою системою

Перевіряється зв'язка **наш шлюз -> Інтернет -> сервіс Postman Echo**.

Шлюз надсилає запит `https://postman-echo.com/get?orderId=ORD-001&total=270` і повертає отримані від сервісу дані. Сума приходить як текст (`"270"`), тому шлюз перетворює її на число через `Number()`.

```javascript
const gateway = new ExternalEchoGateway();

const result = await gateway.sendOrder('ORD-001', 270);

expect(result).toEqual({ orderId: 'ORD-001', total: 270 });
```

| Вхідні дані | Очікувано | Отримано | Результат |
| :--- | :--- | :--- | :--- |
| номер `ORD-001`, сума `270` | `{ orderId: 'ORD-001', total: 270 }` | `{ orderId: 'ORD-001', total: 270 }` | Пройдено |

![Рисунок 3 - Тест із зовнішньою системою: 1 пройдено](screenshots/03-system-integration.png)

Перевірив, що буде, якщо Інтернет недоступний, і ще раз запустив усі тести командою `npx vitest run`.

## Висновок
